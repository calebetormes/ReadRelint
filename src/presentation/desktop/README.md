# Interface Desktop (`src/presentation/desktop/`)

Esta pasta contém o **painel de controle Desktop** da aplicação.

## 📌 Tecnologia Utilizada:
* **CustomTkinter:** Biblioteca Python para criação de interfaces nativas modernas com suporte a tema escuro.

## 📄 Arquivos Contidos:

* **[desktop_app.py](file:///d:/www/ReadRelint/src/presentation/desktop/desktop_app.py):** Aplicação Desktop gráfica que permite ao operador selecionar diretórios para varredura, iniciar/parar o monitoramento automático via `FolderWatcher` e acompanhar a fila de processamento e logs em tempo real.
