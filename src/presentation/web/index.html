ReadRelint — Sistema de Inteligência Policial

O ReadRelint é uma plataforma local de inteligência voltada ao processamento, extração cognitiva e análise de Relatórios de Inteligência (RELINTs). O sistema opera 100% offline, garantindo sigilo absoluto dos documentos.

Versão do Sistema v2.0.0 (FastAPI + Web SPA)
Motor Cognitivo Ollama NLP Local
Banco de Dados SQLite3 (WAL Mode)
Design System Resend Dark System
Desenvolvido para análise inteligente e curadoria automatizada de boletins de ocorrência e inteligência policial.
