# Camada de Apresentação (`src/presentation/`)

Esta pasta armazena as **interfaces de usuário (UI)** do sistema **ReadRelint**.

## 📌 Interfaces Disponíveis:

* **[desktop/](file:///d:/www/ReadRelint/src/presentation/desktop):** Painel Desktop local desenvolvido em **CustomTkinter** para controle de execução, seleção de pastas e monitoramento de logs.
* **[web_dashboard/](file:///d:/www/ReadRelint/src/presentation/web_dashboard):** Interface Web avançada desenvolvida em **Streamlit** para visualização Master-Detail, curadoria, busca e cruzamento de vínculos de inteligência.
