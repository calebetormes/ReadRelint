# Diretório `.ai_context/`

Esta pasta armazena os arquivos de **documentação e contexto da IA**, servindo como a "fonte única da verdade" sobre o blueprint, a arquitetura, os princípios de design, as decisões de arquitetura (ADRs) e a evolução do projeto **ReadRelint**.

Para evitar redundâncias e facilitar o *context window* da IA, a estrutura está consolidada em 3 arquivos fundamentais.

## 📄 Arquivos Contidos:

* **[01_project_blueprint.md](file:///d:/www/ReadRelint/.ai_context/01_project_blueprint.md):** O documento mestre fundacional. Contém as Regras de Ouro (ex: privacidade local, idioma e Clean Architecture), o pipeline ETL detalhado, a estrutura do banco SQLite e o mapa unificado de pastas do repositório.
* **[02_project_state.md](file:///d:/www/ReadRelint/.ai_context/02_project_state.md):** O quadro de acompanhamento contínuo. Detalha tudo que já foi desenvolvido no software e as tarefas que estão em *Backlog* para implementações futuras.
* **[03_decisions_and_workflow.md](file:///d:/www/ReadRelint/.ai_context/03_decisions_and_workflow.md):** O manual de operações técnicas da IA. Guarda os registros das Decisões de Arquitetura (ADRs) explicando o porquê de escolhas técnicas (SQLite, PyMuPDF, Ollama) e possui os *scripts* práticos de interação para inícios/términos de sessões.
